# 300-frame benchmark artifacts

The committed 300-frame summaries are:

- `../onnx/orangepi_infer_stats.json` (ONNX Runtime)
- `../rknn/orangepi_infer_stats.json` (RKNN)

Both contain `frame_count=300`, mean and sample standard deviation in milliseconds.
Current binaries write per-frame JSONL to `../onnx/orangepi_300f_raw.jsonl` or `../rknn/orangepi_300f_raw.jsonl` and the summary alongside it. The historical summaries predate raw capture, so those raw files are generated by the next reproducible run rather than fabricated from the means.
